개인정보처리방침

원상복구114는 무료 철거·원상복구 예상견적 제공 및 상담을 위해 이름, 전화번호, 현장정보, 업로드 영상·사진을 처리합니다.

수집·이용 목적

예상견적 산출, 견적 문의 확인, 상담 연락, 서비스 품질 개선 및 오류 확인.

외부 API 처리

영상·사진 분석 기능을 사용하는 경우 현장 영상과 분석에 필요한 현장정보가 Google Gemini API 등 설정된 외부 분석 서비스로 전송될 수 있습니다. 서비스 운영자는 실제 사용 API와 처리 조건을 오픈 전 최종 고지해야 합니다.

보관 및 삭제

업로드된 원본 영상·사진은 견적 확인 및 상담을 위해 접수일로부터 최대 30일간 보관한 뒤 자동 삭제합니다. 고객의 이름·전화번호·견적결과 등 상담기록은 상담 및 서비스 운영에 필요한 기간 동안 보관하며, 관련 법령상 별도 보관 의무가 없는 경우 목적 달성 후 삭제합니다.

동의 거부

동의를 거부할 수 있으나, 영상·사진 기반 무료견적 기능 이용이 제한될 수 있습니다.

※ 개인정보 보호책임자, 연락처, 사용하는 외부 API 사업자와 국외이전 해당 여부는 정식 오픈 전에 반드시 확정해 보완해야 합니다.
