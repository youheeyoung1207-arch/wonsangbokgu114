# Calibration safety policy

2026-09-02 검증 강화.

- 블로그 글과 회계 원본이 동일 현장임이 100% 확인되지 않은 매칭은 가격 보정(calibration)에 사용하지 않는다.
- 기존 historical_matches.json의 calibration_eligible=true 항목은 원본 증빙 재검증 전까지 모두 false로 전환했다.
- 특히 판교 300평 한정식 현장 ↔ 6월29일 성남 진풍정 철거공사는 이름/지역/시기상 후보이나 동일 현장임을 현재 자료만으로 확정할 수 없어 제외한다.
- 7월11일 진풍정 총 정산 행은 통합 손익표 자체에서도 확인필요 상태이므로 가격 보정에 사용하지 않는다.
- 향후 원본 HWP/계약서/현장명 등으로 동일 현장과 비용 범위가 확인된 건만 true로 복구한다.


## 2026-09-02 손익 데이터 안전조치
- 사용자 확인: 실제 사업에서 적자 현장은 없었음.
- 따라서 통합 손익표에서 음수 순수익으로 파싱된 행은 실제 적자 사실로 취급하지 않는다.
- 가능 원인: 서로 다른 현장 매칭, 매출 누락, 중간/총정산 중복, 복합공사 비용 혼입, HWP 표 파싱 오류.
- 현재 blog↔손익 후보 20건은 전부 calibration_eligible=false, financial_verified=false로 잠금.
- 원본 HWP/계약서/정산서로 동일 현장과 회계 범위가 확인된 건만 수동으로 true 전환한다.
- 검증되지 않은 매출·지출·순수익은 견적 금액, 단가 학습, 오차보정에 절대 사용하지 않는다.
